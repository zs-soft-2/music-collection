# Munkaszabályok

## Módosítás csak tickethez kötve

A repóban minden módosításhoz (kód, konfiguráció, fordítás, dokumentáció) tartoznia kell egy GitHub issue-nak.

- Ha a munkához még nincs issue, előbb nyiss egyet, és csak utána kezdj bele.
- A kommit üzenete hivatkozzon az issue számára, például `(#64)`.
- Kérdésre válaszolni, hibát kivizsgálni és kódot olvasni ticket nélkül is lehet. A szabály a repó fájljainak módosítására vonatkozik.
